# Documentation

Protocol, schema, and pre-registered decision rules.

Rules are written down **before** the data is examined — thresholds, what counts as a hit against the key, the endorsement rate below which a planted item is dropped, and what result would count as evidence against the hypothesis. Committing to these in advance is what makes the result a finding rather than a story, and the files here are dated so the order is verifiable.

Expected contents as the project develops: the corpus and key schema; the reviewer protocol, including the one-way ordering of the two reviewer tasks; the scoring procedure for matching free-text review comments to keyed items; and the analysis plan.
