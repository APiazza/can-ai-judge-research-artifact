# Results

Run outputs.

Raw model responses and any identifiable reviewer data are gitignored. What belongs here in version control is derived, non-identifying output: scored tables, summary statistics, and figures — the things a reader needs in order to check the analysis without needing the raw responses.

Every run records the model, the prompt rung and template version, the date, and the corpus version, so that any figure can be traced back to the exact conditions that produced it.
